How the RLadies+ Guide itself is put together, and how to contribute to it.

The guide lives at [rladies/rladiesguide](https://github.com/rladies/rladiesguide) and is published to <https://guide.rladies.org> on every merge to `main`.
It is a [Hugo](https://gohugo.io/) site using the [Relearn theme](https://mcshelby.github.io/hugo-theme-relearn/).

If you want to add or fix something and are not sure where it belongs, start with [Content structure]({{% relref "guide/content-structure" %}}).
If you know what you want to write and need the mechanics, go to [Contributing to the guide]({{% relref "guide/contributing" %}}).
